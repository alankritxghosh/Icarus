**Goal:** A native macOS menu-bar app — the *face* — that summons on a global hotkey, takes a
question (typed first, spoken later), and shows a cited answer or an honest "No one wrote this
down" in a floating overlay, with the answer optionally spoken back. The app thinks nothing
itself; it is a thin client over the already-proven Python brain at `http://127.0.0.1:8000`.

**Architecture:** Face ↔ wire ↔ brain. The Swift app (AppKit-driven SwiftUI) owns the
hotkey, overlay, mic, and speech; it talks to the unchanged Python brain (`demo/server.py`
over `GatedPipeline`) over localhost HTTP. No Python is embedded in the app. Voice is
on-device and free (WhisperKit STT on the Neural Engine; `AVSpeechSynthesizer` TTS).

**Tech Stack:** Swift 6 + SwiftUI + AppKit (`NSApplicationDelegateAdaptor`, `NSStatusItem`,
`NSPanel`) · `KeyboardShortcuts` SPM package (global hotkey) · `URLSession` + `Codable`
(the wire) · `WhisperKit` SPM package (STT) · `AVSpeechSynthesizer` (TTS) · `XCTest`
(the wire's tests). Python brain unchanged.

## The one non-negotiable (restated for this phase)

The app **never** decides whether an answer is grounded. It sends the question to the brain
and renders exactly what the brain returns (`verdict`, `answer`, `citations`, `searched`).
Any Swift code that inspected or overrode the verdict would break the promise — forbidden.

## Verification philosophy (read before coding)

The Python eval board does not test Swift UI. So:
1. **The brain stays green** — `python3 -m evals.run --pipeline gated` + the demo tests are
   the conscience; unchanged, must stay green.
2. **The wire is unit-tested in Swift (XCTest)** — given canned brain JSON, the client
   decodes `verdict`/`answer`/`citations` and maps citation→GitHub URL. This is the part most
   likely to rot silently, so it is real TDD (Task A3.x).
3. **The UI is verified by hand** on the two demo heroes — each UI task states an explicit
   manual success check. We never claim a task done without performing that check.

### Task A3.3: The client + render

**Step 1 — `BrainClient.swift`:**
```swift
import Foundation

struct BrainClient {
    var base = URL(string: "http://127.0.0.1:8000")!

    func ask(_ question: String) async throws -> AskResponse {
        var req = URLRequest(url: base.appending(path: "ask"))
        req.httpMethod = "POST"
        req.setValue("application/json", forHTTPHeaderField: "Content-Type")
        req.httpBody = try JSONSerialization.data(withJSONObject: ["question": question])
        let (data, resp) = try await URLSession.shared.data(for: req)
        guard let http = resp as? HTTPURLResponse, http.statusCode == 200 else {
            throw URLError(.badServerResponse)
        }
        return try JSONDecoder().decode(AskResponse.self, from: data)
    }

    func health() async -> Bool {
        guard let (data, _) = try? await URLSession.shared.data(from: base.appending(path: "health")),
              let h = try? JSONDecoder().decode(Health.self, from: data) else { return false }
        return h.ok
    }
}
```

## Risks & honest unknowns
- **Swift is new ground** — A1–A3 are deliberately small to build the muscle before voice.
- **Brain startup UX deferred** — dev/demo runs `python3 -m demo.server` manually; bundling a
  signed Python into the `.app` for a non-technical end user is a separate, later job.
- **WhisperKit first-run model download** needs network + disk; pick the smallest accurate
  model, measured.
- **End-to-end latency** (mic→transcribe→retrieve→writer→gate→speak) is unproven; measure at
  A4/A5, don't promise a number.
- **Signing / notarization / App Store** out of scope for the demo; deferred.
- **Rotate the exposed provider keys** (HANDOFF §10) before any live `/ask` run.

## Out of scope (deliberately not built)
- Cluely-style screen-capture invisibility — violates "never capture the screen silently."
- Windows/Linux (native Swift is Mac-only this phase).
- Embedding Python in the app bundle (HTTP-to-localhost instead).
- Private repos / paid models (shelved upstream).
- Cloud hosting (the unified-cloud + per-tenant-isolation decision is post-demo; see
  [docs/decisions/2026-06-30-unified-cloud-per-tenant-isolation.md](../decisions/2026-06-30-unified-cloud-per-tenant-isolation.md)).
