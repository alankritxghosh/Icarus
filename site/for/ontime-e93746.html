Questions a new contributor would ask

answeredWhat was causing a countToEnd to lead to incorrect expected times?

The server incorrectly calculated expected end times by using expectedStart + duration while ignoring the countToEnd property, which caused projected end times to drift significantly when events ran in overtime. Additionally, the system failed to break the link chain after a countToEnd event, leading to further calculation errors.

pr2108
answeredWhy was the time-linking model inverted so that editing a start stretches the previous event?

The model was inverted to change the mental model to 'an event's end flows into the next event's start,' replacing the previous system where events were chained forward and start inputs were disabled when linked.

answeredWhy was a self-contained legacy timer viewer added for old browsers?

The self-contained legacy timer viewer was added to support browsers that do not support Promise.any and cannot parse the Vite-built React bundle.

answeredWhy was the timer-legacy view not served in desktop distributions?

The timer-legacy view was not served in desktop distributions because the electron packaging failed to copy the necessary HTML files, causing a 404 error. Additionally, on Linux, the AppImage mount point contained a hidden directory, and Express's sendFile method refused paths with dot-segments by default.

answeredWhy are progress bars interpolated on the client?

Progress bars are interpolated on the client to remove a visual lag of approximately one second and ensure the progress fill tracks real time, reaching 100% exactly when the timer hits zero.

Zod request validation was introduced to replace hand-written JSON Schema literals that lacked runtime validation, ensuring that tool arguments are parsed and validated before being used in business logic.

answeredWhy is ontime built as a self-hosted server rather than a cloud service?

Ontime is built as a node server that can run as a standalone application, which allows it to be hosted on a headless machine for fixed installations in venues or complex systems, or hosted in the cloud as an online service.
