Questions a new contributor would ask

answeredWhy does the thumbnail component use an img element instead of a background-image?

The thumbnail component uses an img element because background-image often failed to render correctly with wide filmstrips due to how Electron and Chrome handle image rendering. This issue caused thumbnails to appear as empty boxes or flicker when resizing the window.

answeredWhy does the app use birthtimeMs instead of ctimeMs as the file created time?

The app uses birthtimeMs because ctime stands for "change time" rather than "created time," and birthtimeMs is the correct property for file creation time according to Node.js documentation.

pr549
answeredWhy does the app hash a subfile rather than the whole video file?

The app hashes parts of the file (the beginning, middle, and end) combined with the file size so that the hash is based on the actual content rather than metadata. This allows files to be renamed or moved without losing their thumbnails, ensures the same file with different names uses the same thumbnails, and enables easy duplicate detection.

pr611
answeredWhat was causing the window position to be wrong on Windows 10 after maximize, close and reopen?

The issue was caused by using getBounds() to save the window position, which included the coordinates of the hidden frame (-8px, -8px) when using a frameless BrowserWindow. This was resolved by switching to getContentBounds() to export the correct coordinates.

answeredWhy did the project replace npm with yarn?

The project replaced npm with yarn because yarn behaves better across different execution environments, specifically resolving issues where npm failed to install dependencies like 'fsevents' in GitHub Actions.

Releasing off-screen media was implemented to reduce sustained heat and stuttering during gallery autoplay on machines with a finite hardware video-decode pool.
