answeredWhy was rotation modified to prevent download errors?

Rotation was modified because rotating an image four times resulted in a 360-degree value in the download URL, which caused IIIF image servers to throw errors. The fix uses modulo 360 to ensure the rotation resets to 0 instead of 360.
