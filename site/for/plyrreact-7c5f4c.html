answeredWhy does the library expose a ref based API?

The library exposes a ref-based API to provide a wrapper around the component that allows parent components to safely access the Plyr instance via an API object (shape: { plyr: PlyrInstance }). This approach was adopted to make the component more "React-ish" by moving away from direct access to the underlying HTMLVideoElement.
