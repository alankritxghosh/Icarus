answeredWhy does the player not patch out the pssh box on DStv's Streama set-top box?

The DStv Streama set-top box refuses to bufferize media segments if the pssh box has been patched out (replaced with a free box). Consequently, the player was updated to disable this optimization specifically for that device.

answeredWhy was Retry-After honored for HTTP 429 retries?

The Retry-After header is honored for HTTP 429 retries to respect the server's preferred minimal backoff time, treating it as a minimum retry delay without weakening the existing client-side exponential backoff policy.

answeredWhy does TTML not apply percentage line heights?

TTML percentage line heights are not applied because they are complex to implement due to differences in how TTML and CSS apply styles: lineHeight is applied to a p element in TTML, while fontSize is applied to a span, leading to potential mismatches in computed values.

answeredWhat caused a streamEvent to be sent twice when reloading while inside it?

When reloading, the StreamEventsEmitter was re-created, causing it to lose its previous context. For events with a duration, if the reload occurred within the event's time interval, the emitter would incorrectly trigger the event again upon resuming playback.

answeredWhy does playback continue if the text displayer fails to initialize?

Playback continues if the text displayer fails to initialize to prevent the RxPlayer from hanging indefinitely in a LOADING state, allowing it to proceed without displaying subtitles.

answeredWhat precision difference was triggering content boundaries warnings?

The warnings were triggered by floating-point precision discrepancies between the media element's current time and the Manifest-derived boundaries, which caused the playback position to appear marginally outside of the allowed range.

answeredWhy does CMCD not set deadline and rtp when the playback rate is zero or below?

The deadline (dl) and requested maximum throughput (rtp) are indirectly dependent on the playback rate, and when the rate is 0 or negative, these values are difficult to determine or could result in meaningless data like 'Infinity'. Therefore, the system avoids setting them in these cases to prevent providing incorrect information.
