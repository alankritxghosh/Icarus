# Swipe file — external posts, and the mechanism extracted

## Status: EMPTY — deliberately

**Zero entries. No post has been captured yet.**

This file is not seeded with remembered examples. A swipe entry built from
recall rather than a captured post is exactly the fabrication class the product
exists to refuse, and a paraphrased hook from memory is worse than no entry —
it teaches a mechanism that may never have existed.

**Rule:** no entry without a real captured post — URL, author handle, and the
text as written.

## What to capture

Not "posts that did numbers." Posts by people the primary segment (`audience.md`)
actually reads: agent-tooling builders, retrieval/eval people, devtool founders
who write technically. A viral post from a generic AI-founder account is an
anti-example and belongs in § Anti-examples, not in the main file.

## Entry template

```markdown
### [short label] — @handle — YYYY-MM-DD
**URL:**
**Format:** standalone / reply / thread / video / image
**The post:**
> verbatim, including line breaks

**Metrics at capture:** views / likes / replies / reposts / bookmarks (note capture time)
**Subject:**
**Audience it was written for:**
**Hook:** (first line, quoted)
**Mechanism:** (which of the six in `hooks.md` — or a new one, named)
**Structure:** (beat by beat)
**CTA:** (or none)
**Why it worked:** (mechanism, not vibes — "it was relatable" is not an answer)
**Transferable?** yes / no / only-with-our-material — and *why*
**Where it would apply here:** (a specific item in `content-pillars.md`, or none)
```

## Anti-examples — also worth capturing

A post that did huge numbers via a mechanism we will not use (engagement bait,
manufactured controversy, fake vulnerability) is worth one entry so the pattern
is recognisable, with **`Transferable? no`** and the reason. One or two are
enough; a catalogue of them is a distraction.

## Capture cadence

3 posts/week while running Play A (`strategy.md`) — you are already reading the
feed to reply into it, so capture costs almost nothing on top. Below that rate,
this file is not being maintained and should be marked so, not quietly padded.
