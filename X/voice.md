# Voice — the mechanisms, not the record

**The record lives in the vault:** `~/Documents/Obsidian Vault/Icarus/X
Content.md` § Voice & what works. That file is authoritative for what the voice
*is*, derived from 11 captured posts. Read it before drafting.

This file answers the question the vault does not: **why does it work**, so the
voice can be extended to new material rather than imitated.

## The five devices, and the mechanism under each

### 1. The contrast pair
> "Code shows what exists. Not why it exists."
> "A merged PR leaves a commit. A refused one leaves nothing."

**Mechanism:** an information gap opened and half-closed in one breath. The
first clause is something the reader already believes; the second removes it.
The reader cannot resolve the tension without reading on. This is the account's
highest-performing structure and the cheapest to reproduce, because engineering
findings are natively shaped like this — *the thing you assumed / what is
actually true*.

**How to generate one:** take any finding in `content-pillars.md` and write the
belief it overturned as the first line.

### 2. The unrounded number as the first fact
> "17,810 agent skills in one library."
> "One repo showed 1,283 pull requests closed without merging."

**Mechanism:** specificity is a costly signal. `1,283` cannot be guessed, so it
proves work happened before the reader has evaluated any claim. A rounded number
("over a thousand") destroys the signal at zero benefit.

**The failure mode this fixes:** the Aug 17 five-second-test post. Strip the
specifics from a real learning and you get an aphorism — which reads as
generated, because it could have been.

### 3. One thought per line
**Mechanism:** on a phone, a paragraph is one visual object and gets one
attention decision. Four lines get four. Each break is a micro-commitment
the reader has already made, and each is cheap to honour.

**Cost:** line breaks eat characters against the 280 limit and the composer
strips them on long pastes. Count characters every time.

### 4. The observation opener
> "Watched a coding agent about to write a patch two people had already had
> rejected."

**Mechanism:** the reader is placed at a scene, not at a pitch. "I built X"
requires the reader to already care about you. "Watched an agent about to…"
requires only that they care about agents. On an account with no following,
that difference is the whole ballgame.

### 5. Flat delivery of a hard fact
No hedging before, no lesson after. The Aug 15 post ends on "Live today." — no
explanation of why it matters. **Trusting the reader to draw the conclusion is
what makes the account read as an engineer's and not a marketer's.**

## The structural template that produced the best-written post

Observation → mechanism → product. Three beats, ~40 words.

> Watched a coding agent about to write a patch two people had already had
> rejected. / Nothing in the repo could warn it. A merged PR leaves a commit. A
> refused one leaves nothing. / Icarus tells it first.

The product arrives *third*, as the resolution of a problem the reader now
believes in. Reverse the order and it is an ad.

## Register violations to catch in review

| Symptom | Example | Fix |
|---|---|---|
| Aphorism with no number | "A maintainer decides in about five seconds" | Restore the specific, keep it about work done |
| Institutional cadence | "It reads a repository's code and GitHub history, then returns cited context" | Break into contrast lines; lead on what was seen |
| Conclusion supplied for the reader | "…which shows why context matters" | Delete the clause |
| Rounded quantity | "hundreds of PRs" | Use the count or cut the sentence |
| Product before problem | "Icarus now supports X" | Move product to beat three |

## The open tension

The measured data says vulnerable personal posts reach furthest (178 / 154 /
123 views, both replies ever). The standing rule forbids disclosing defeats.
**These conflict, and the conflict is intentional and decided.** The resolution
in force: personal posts continue, sourced from *work done* — real repo numbers,
real sessions — not from struggles confessed. Whether that preserves the reach
is genuinely unknown and is `hypotheses.md` H4.
